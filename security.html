Security

How this website handles security today.

HTTPS only

Every page is served over HTTPS. Plain HTTP requests are redirected to HTTPS.

A static site

This website has no logins, accounts or database. It loads no analytics or ad trackers.

Demos run on fictional data

The demos use invented companies and sample files. They run in your browser and don’t upload your files or send what you do in them to us.

The contact form

The form is sent over HTTPS to FormSubmit, which emails it to us. We use it only to reply. Please don’t include client data, tax IDs or bank details. See the Privacy notice for details.

Report a vulnerability

Email contact@sophonfinance.com with “Security” in the subject. Include the page, the steps to reproduce and what you found.

Please test only against your own data, don’t disrupt the site, and give us time to fix the issue before sharing it.

Security documentation is available on request at contact@sophonfinance.com.
